# 包内内容与必要性

| 内容 | 必要用途 |
|---|---|
| 根 SKILL、SOP、模板与运行说明 | 唯一入口、完整流程、项目结构与用户审核 |
| ENGINE_GUIDE、风格/版式/开头规范、WHITEBOARD_GRAMMAR_Y3、CRAFT_LESSONS | 从脚本到镜头及事件表的技术指导、节奏手感与易错点 |
| 人物规范、提示词、画风图和手形 | 保持表演和构图规范；参考图只定风格，不锁定脸和姿势 |
| 音频规范、火山与免费微软配音实现、凭证空模板 | 全文一次合成、时间戳、失败去重和本机私密配置 |
| 封面规格/美术指导、完整中文 TTF | 先理念、代码准确排字、AI 插画、审核及首 6 帧 |
| 混音脚本、音乐授权/响度登记（不含歌曲） | 自动选曲与音量；使用者自备可商用曲目 |
| 手绘引擎、QA、基础库与字体 | 实际加载依赖与传递依赖 |
| 自检脚本、回归测试、烟雾测试、清单与打包工具 | 验证单包、拒绝多余入口/私密文件 |
| SOURCES、许可 | 来源与改动可追溯 |

公开版不含：品牌 Logo、固定人物/服饰/版式参考图、样板案例、配乐。

# 开头规范（前 5 秒）

**生效：2026-10-14（用户要求）。适用：Why-HandDrawn-Video 的所有视频，包括新做、重做、改版；此前已交付的旧成片不追溯，但再次改版或重渲染时必须一并改到符合本文（旧项目重跑 `qa_project.py` 开头检测不通过是预期的，不是新故障）。本文件是开头规则的唯一权威来源；其他文件只引用，不另写数字。**
它取代并合并以前的两条旧规则：「开头 3 秒必须画人」「hero 起笔 ≤ 0.5 s」。旧写法和本文冲突时，以本文为准。

## 一句话版本
开头 5 秒里，画面除了字幕，必须一直有新的笔画在出现；第一笔画的是人，而且 0.5 秒内就落笔；任何一段静止都不能超过 1 秒。

## 三条硬指标（缺一不可）
1. **先画人**：第一块画板的人物（`hero`）起笔时间 ≤ 0.5 s。不许用空白板或纯文字开场。
2. **不静止**：0–5 s 内，任意连续 1.0 s 的时间段里，画板上都必须有新笔画正在被画出来。静止超过 1.0 s 就是不合格。
3. **字幕不算动画**：字幕、标题栏、右上角小时钟、镜头平移，都不算"画面在动"。靠它们凑出来的动，不算数。

## 名词解释（避免各自理解）
- **新笔画 / 有效动画事件**：事件表（`design/film.py`）里 `dur ≥ 0.2 s` 的事件——人物笔画、写字、线条、方框、圈、叉、勾、箭头、下划线。小于 0.2 s 的碎点、短线、不在口播里的装饰涂鸦，不算。
- **静止**：画板区（portrait 为 y285–1430，landscape 为 y190–900；由 hdv/layout.py 读取，不含标题栏、不含底部字幕带）里没有任何新笔画。人物已经画完、字已经写完、只是挂在那里，也算静止。
- **计时起点**：事件表里的 0 s = 正片开始。成片前面接了 6 帧封面（0.2 s，也是静止），所以在最终成片里复核时，封面的 0.2 s 要算进第一段静止里。

## 怎么做：口播说什么，就画什么，画在说出来的那一刻
1. 口播说到一个具体的东西（门、手机、书包、日历、教室）→ 当场画一个简笔线稿（`box`、`line`）。
2. 口播说到状态或结论的关键词 → 当场写出来，重点用橙色。
3. 口播说"好了、做到了、没问题" → 打勾；说"不是、没有、不对" → 画叉；说到要强调的词 → 用 `ring()` 圈起来；说到数字或时间 → 写出来，再圈或画下划线。
4. 画的东西只能来自口播里说到的内容，不补造脚本没有的情节（沿用 `references/workspace/CHARACTER_VISUAL_STANDARD.md`）。先看开场源图并登记已存在的物件；不重复重画已清楚可见的物件，也不让新增线条遮挡它们、人物表情或动作。开场目检必须对照源图和逐帧画面，不能只看事件表或完成帧。
5. 屏幕上的文字取口播原文的片段，不改写、不缩写成别的说法（`sync_report.py` 会标出对不上的文字）。
6. 节奏参考：前 5 秒里，大约每个口播短语（1–2 秒）至少画出一个新元素；人物画完后，立刻接着画元素、写字或圈标记，不要停下来等口播。
7. 前 5 秒的做法清单里**不包含**：缓慢推拉镜头、整张图淡入、让手"悬着不动"、重复描一遍已经画好的线。
8. 每个圈、叉、勾、箭头等符号都要写明对应的口播短语和具体含义。叉只用于明确的否定/取消语义，勾只用于明确的完成/肯定语义；没有对应含义就删掉，不能作为填空或装饰。“听见钟表声”只能支持钟表/声音表达，不能推导出叉号、禁止或取消含义。

## 和其他规则的关系（对抗性审查后的结论）
- **橙色上限**：每块画板橙色元素 ≤ 3–4 个（`LAYOUT_LIBRARY.md` 节奏规则）。开头加了很多元素，勾、叉等非重点标记默认用墨色（`check(..., INK)`），橙色只留给真正的重点词和圈。
- **文字和人物**：新增的字和线条不得压在人物身上，也不得互相重叠；事件表自检会拦文字互压和线条穿字，**但不检查"压人物"，要靠目检**（见下面第 C 项）。
- **画板边界**：portrait 人物水平范围40–1040、文字右边界≤1040；landscape 使用x80–1840、内容y190–900，文字底≤890。开头的新元素同样适用。
- **窗口**：一块画板的所有事件必须在该板窗口内结束；镜头在下一块起点前 0.5 s 开始离开，最后一笔最晚在离开后 0.2 s 内画完（事件表自检拦截）。开头第一块画板通常长 6–8 s，5 秒内的新元素都在这个窗口里。
- **源图物件**：开场源图中的清晰物件只由源图负责；除非口播明确要求强调且新画法不会重叠，否则不再用代码重描。源图中已有钟表时，不再叠画第二个钟表、指针或刻度。
- **封面帧**：成片开头 6 帧封面保持不变（`COVER_SPEC.md` 第 7 节）；它的 0.2 s 静止算进"第一段静止"，所以 `hero` 起笔不能晚于 0.5 s，总的第一段静止也不能超过 1.0 s。
- **样板「小宇」**：它的开头（`hero` 0.55 s 起笔、开头动画稀疏）早于本规范，**开头一律以本文为准**；样板里的字体、版式、笔画风格、剪辑节奏仍然有效。
- **适用范围**：只管前 5 秒。5 秒之后仍按原来的节奏规则（每块 6–14 个事件，首笔在板起点后 0.1–0.55 s，等等）。

## 怎么查（A、B、C 三项都要做，缺一不算合格）
**A. 事件表自检（自动）**：运行 `python design/film.py`，库 `hdv` 会同时检查"第一块 `hero` 起笔 ≤ 0.5 s"和"0–5 s 内静止 ≤ 1.0 s"，不通过就拒绝输出 spec，并写出是哪一段静止。
　注意：每个项目的 `design/hdv/` 是新建项目时复制的旧库。2026-10-14 之前建的项目没有这条检查，要把 Skill 里的 `scripts/hdv/lint.py` 和 `scripts/hdv/dsl.py` 复制过去，再重跑。

**B. 视频检测（独立，看渲染结果）**：
```
python <skill>/scripts/opening_check.py --video renders/<名>-final-vNN.mp4
```
它逐帧比较画板区的变化，输出 `qc/opening-check.json` 和 `qc/opening-check.md`，有静止超过 1.0 s 就退出码 1。
成片开头有 0.2 s 封面，封面→正片的硬切会产生大量像素变化，脚本默认忽略开头 0.25 s 内的变化（`--ignore-start`），否则封面的静止会被"重置"而漏判；对没有封面的预览版（`visual`）要传 `--ignore-start 0`。
它把镜头平移也当作"在动"，所以不能单靠它判合格；它是检查渲染结果有没有和事件表一致，A 才是主判据。

**C. 目检**：从最终成片抽 0.9、1.9、2.7、3.6、4.4、5.2 s 等帧，逐张确认：① 新元素和当时的口播对得上；② 没有压在人物或源图已有物件上、没有重复描画；③ 符号含义有原文依据；④ 没有出界、没有互相重叠；⑤ 橙色元素没超过上限。

## 常见错误（出现就重做）
- 人物画完就停，等口播说完下一句再动（典型：2–5 s 之间一片空白）。
- 用一堆小点、小短线凑"有动作"。
- 画了和口播无关的装饰。
- 所有新元素都用橙色。
- 屏幕上写的字是改写过的（比如口播"早上明明起来了"，屏幕写成"早上起来了"）。

## 对抗性回归规则
- 对每一个新笔画都做反向提问：原稿哪几个字支持它？源图里是否已经有同一物件？符号会不会让家长读出原稿没有的否定/肯定结论？任一项答不清就删除该笔画。
- 开头抽帧除了看新元素是否出现，还须逐帧比对底图已存在物件和角色：重复、覆盖、符号误义都判失败，即使动画连续性和自动开头检测通过也不能放行。

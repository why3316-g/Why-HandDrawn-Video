# 画板版式库

样板 14 块画板的做法，换口播时按"意思单元"套用。以下为 portrait 坐标：宽 1080，可见区 y 285–1455，板内 x 从 0 起。landscape 构图与坐标读 LANDSCAPE_SPEC.md；不要缩放本页竖屏坐标。

## 坐标约定（踩过的坑）
- `text(i, s, x, y, size, …)` 的 **y 是文字基线**，不是顶部：字占据 y-0.82×size 到 y+0.12×size，字宽 CJK = 字号。
- 圈字用 `ring(i, s, x, y, size, at)`（参数和 text 一致，按字的真实位置算圈）；不要手写 `ell(...)` 去圈字。小彬片 2026-10-12 就是手写坐标时把 y 当顶部，两处圈整个落在字下面。
- 事件表生成时会自动做版面自检（出界、文字重叠/行距过紧、线条穿字、圈没圈住），有 ✗ 就不输出。

## 通用骨架
```
panel(i, 'id', 该意思单元首句起点 - .1)
hero(i, 'id', 人物中心x, 顶y, 高, 起笔, 时长)    # 起笔 = 起点 + 0.2~0.4；高 560–700；宽按图比例自动
text(i, '关键词', 100, y, size, S('口播原词'), dur, 颜色)   # 关键词用橙，铺垫用墨色
```
- 左栏文字 x=100：y≈455/545/635 放上部，y≈1335/1405 放下部（离字幕带 y1438 要有余量）。
- 人物放左（cx≈300–330）时道具放右（x≈660–900），反之亦然；人物与文字不重叠。
- 底部两行总结式文字（y1335、1405）用于"结论/转折"句。

## 单画板展示多个家庭情况

这里的多人指多个不同家庭/个案，而不是一个家庭里的多个人。一个画板最多并列 2–3 个脚本已有的家庭情况；每个小场景单独成组，不能共享家具、房间背景或视线。1080×1920 竖板保留顶部标题区、人物场景区、口播文字区和底部字幕带安全区。场景用留白、少量分隔线或不同景别区分，不加虚构编号/标签。生成候选图前先确认原稿确实提到对应的几户/几种情况。

三种版式图均已由用户审核通过，保存在 `assets/layouts/multi-household-v01/`，供后续工作流按板选用；同一视频不同画板可用不同方案。图片只参考空间层级、疏密与留白，不复制其中人物、事实、文字、道具或背景。可在 `shots.json` 对应整板镜头填写 `layout_reference_images`，值为资产相对路径数组；生图脚本会把它们作为仅构图参考，并另附 `style_ref`。不要把这个字段用于单角色镜头。

| 编号 | 版式 | 构图方式 | 适合的口播节奏 |
|---|---|---|---|
| A | 主次错落 | 一个较大的主场景，两个较小独立插景放在对角留白处；避免小插景挤到标题和字幕区 | 先讲一个重点家庭，再顺带补充另外两种情况 |
| B | 纵向三段 | 三个场景从上至下错开，留白或短虚线分隔；每格尺度相近 | 口播依次讲三种家庭情况，重要性相当 |
| C | 三点均衡 | 三个独立场景落在上、中、下斜向位置，大小接近，人物朝向各自场景内部 | 一句话概括多个家庭，画面同时呈现并列关系 |

资产对应：A `assets/layouts/multi-household-v01/A-main-and-supporting.png`；B `assets/layouts/multi-household-v01/B-vertical-three-bands.png`；C `assets/layouts/multi-household-v01/C-balanced-three-points.png`。三张均保留，不要求整条视频只选一款。

每个小场景按原稿指定人物和情绪单独验收；不可为了画面丰富给所有小场景添加完整家庭成员。

## 节奏规则
- 每块 6–14 个事件；首笔在板起点后 0.1–0.55 s。
- **第 1 块画板另按 `OPENING_SPEC.md`**：人物 `hero` 起笔 ≤ 0.5 s；0–5 s 内静止 ≤ 1.0 s；事件数以满足静止上限为准（可以多于其他块，但仍不超过 14 个）；非重点标记（勾、叉）用墨色，保证橙色元素每块 ≤ 3–4 个。
- 文字起笔 = 口播说出该词的瞬间；`dur` = 字数×0.11，上限 0.9。
- 一块画板的所有事件在该板窗口内结束；镜头在下一块起点前 0.5 s 开始离开，最后一笔最晚在离开后 0.2 s 内画完，否则 `film.py` 拒绝输出。块尾的金句要么提前起笔、要么缩短 dur，别让它边写边被平移带走。
- 同一块画板里，橙色元素不超过 3–4 个；整片橙色约占手写字一半。
- 想加的新版式：先看 `examples/xiaoyu/film.py` 是否已有同类；确实没有，写成改编申请。

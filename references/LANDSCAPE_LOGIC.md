# 宽屏：先分析逻辑，再设计画板

本规范适用于所有 landscape 视频。本文件整合已审核的宽屏风格；不改变portrait竖屏规则。用户要求原文直接制作时，逻辑分析只调整视觉表达，不改文案和配音。

## 1. 脚本分析是必做步骤

声音锁定后、表演分镜和生图前，通读完整锁稿，写 `design/logic-plan.json` 和便于阅读的逻辑策划表。样片也先分析全文，再标明本次呈现范围。逐段记录原句、主要及次要关系、节点、关系含义、限定词、呈现方法、跨板承接；不能只摘关键词，不能只分析用户指出的某一秒。

可出现的关系包括但不限于：并列枚举、层级分类、顺序步骤、时间/版本变化、因果、条件、递进、转折对照、定义纠偏、包含/组成、类比、举例归纳、状态变化、系统互动、证据/出处与行动建议。允许其他类型并写清含义；不能强行把每句话归入三种模板。

| 原文关系 | 视觉选择 | 必须避免 |
|---|---|---|
| 同级并列/枚举 | 同宽同高、等距、同基线的卡片/网格；原文有编号则保留编号 | 把章节编号画成治疗顺序、按字数任意大小排名 |
| 层级/包含 | 父子分组、嵌套框、清楚的归属连线 | 把包含关系画成确定的效果因果 |
| 时间/步骤 | 有方向的时间线或步骤连接，保留条件 | 将同时发生的事画成先后必经过程 |
| 因果/条件 | 框和箭头，箭头写明关系，保留“可能/有些/如果/严重”等限定 | 把相关、提示、比喻升级成诊断或必然因果 |
| 递进 | 逐层或分级推进，大小变化须能解释真实层级 | 凡有“而且”都画成由大到小、伪造程度数据 |
| 对照/纠偏 | 两个明确分组，保留完整否定；结构与字级可比 | 只突出被否定的词，或散放一串句子 |
| 类比 | 成对呈现对象，保留“像…一样”等类比桥 | 用因果箭头把类比当作疗效证明 |
| 状态变化/举例 | 无数值的状态示意、同级情境卡，共同归纳 | 无依据的分值、阈值、曲线坐标、风险排名 |
| 系统互动 | 核心与周围角色/因素分组连接 | 给本来共同作用的因素硬排先后 |

一板只讲清一个主关系，必要时保留从属关系；关系类型改变、文字过多或没有统一阅读路径时拆板。仍遵守2.5–8秒和原音轨，不改词句迁就图形。先设计完成态，再排逐笔出现次序；不以“加几个圈/箭头”代替关系设计。

## 2. 由内容选择构图，穿插三类画板

宽屏与竖屏是两种独立风格，共用工具不等于共用版式。宽屏不得整片固定左文字、右人物。分镜表先记录每板关系、视觉主体和构图，再排实际音轨；依据叙述转折穿插以下方式，不为凑比例机械轮换：

- **人物/场景居中**：图像是主体，周围放少量原文关键词，按口播顺序逐步出现；文字不压住人物、已有物件或手势。图中人物表演仍须对应原文。
- **居中逻辑或文字说明**：并列、包含、因果/条件、递进、对照、类比、举例归纳等关系适合完整占用白板；不强塞人物。逻辑图节点、分组、连线与整体阅读路径居中。纯文字说明按语义分组并整体居中，保留关键限定词；不能是一堆随意散句或仅一个章节标题。
- **左右讲解/对照**：人物与文字分区，左右可互换；适合官方原件、具体场景和补充解释。不能将此方式当整片唯一模板。

人物每次出现按镜头表和原图最多2次规则审核；无人板在logic-plan.boards记录`presentation=full_board_logic`或`centered_text`、`space_reason`解释为何文字/关系应成为主体。有人板仍用`presentation=person`，可记录`layout_type=image_centered|split`。旧策划字段兼容。完整逻辑图按事件实际包围盒检查居中与占用；文字板检查文字本身的居中和有效说明，不靠虚画大框骗检查。

**文字美术**：白底墨字，原文关键词可用已有橙色强调，暗色字幕条沿用已审核样式。默认不加橙色或其他颜色的左侧装饰竖条；用字号、行距、留白与关系分组建立层级。先做完成态，再排逐笔，避免人物刚画完即被文字或转场遮住。审片要检查连续几板的构图是否有实质变化，不把简单镜像算内容策划。

## 3. 官方声明、报告、通知等用真实原件

出现具名声明、报告、通知、指南等，先检索发布机构、正式期刊或官方档案中的同名同版本原件。核对标题、发布者、年份/版本；优先用正式封面、PDF首页或官方原文页面截图，保留原始字节、下载/截图方法、链接、日期、许可信息与SHA-256。只展示与本板有关的少量原件区域，标明出处；不假装来自正文的示意图。

找到相符原件就必须使用真实图片，不再用AI伪封面、手写标题加一个框代替。PDF不可取得而官方原文页面可访问时，可以使用真实原文页面截图，明确标作“官方原文页面”，不冒称PDF封面。仅有题录时如实标记“官方题录”，不冒称报告原件；找到原件但访问受阻须记录并处理，不伪造，不绕过验证。未找到相符版本时登记查询和结论，不能拿旧版充新版；影响制作时向用户说明具体缺项。

`documents`清单必须记录所有具名材料。原件以原样图像淡入/展示，不对原件逐笔重画，不修改标题、年份、标志或正文。人物、解释框、原文关键词与原件分区布置。

全文检索清单与本版入镜范围分开：逐板`documents`列本板引用的材料ID，原文关系节点引用到的具名材料也会自动纳入。后半篇的报告不能强迫提前出现在一分钟样片。当前范围的原件必须保持比例、可读尺寸，并在对应画板完整可见至少1秒；最终仍由抽帧检查内容和可读性，不能以1像素小图或片长之外的事件假装使用。

## 4. 手臂与质量闸门

宽屏使用包内`assets/marker-hand-landscape-v01.png`短手素材，手、腕与袖口固定自然比例（当前批准scale=.18），从右下斜向进入；只移动位置/方向，不向画外续接或拉长袖管。袖口自然闭合，后方直接留白；不得出现水平长臂或矩形硬切。竖屏从 `assets/hands/hand-pool-v01/` 随机取图（`HAND_POOL.md`），宽屏**不套用**该素材池、也不被竖屏素材覆盖。

`logic-plan.json`与 `check_logic_plan.py`是宽屏制作输入及检查入口；事件表生成与正式渲染均检查。格式见脚本模块和模板。覆盖检查只能证明全文扫描及画板映射齐全，不能证明语义正确；独立审片必须另查漏掉/强加的逻辑、限定词、箭头指向、同级对齐、跨板承接、构图选择与无人图/文字居中。

技术检查通过不等于好看：手臂横向遮挡、散句堆放、逻辑层级混乱、无人文字/逻辑板散乱或不居中、用伪文献框代替找到的官方图，均属阻断问题，必须在画面版阶段修正。

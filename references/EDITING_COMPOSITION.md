# 排版与落笔规范 v01

用户依据《孩子休学了》项目提出的维护要求。全部正式执行；2026-10-28用户批准情绪和物件，取消常驻标题。适用于口播与歌曲，两者音频规则各自保留。

## 1. 先构图，再确定文字坐标
- 禁止直接套用左上/左下固定坐标。原版式库坐标只是历史示例。
- 每块画板先标人物、脸、手、视线、重要道具、门框等高密度结构的边界，以及字幕安全区；再选文字区域。
- 每板至少比较两种位置，记录选择依据：空间可读性、语义归属、视线引导、情绪留白。不得仅为变化而变化。
- 文字与其解释对象靠近；对比句形成成对结构，因果句形成明确阅读顺序，对话靠说话者，结论形成集中视觉落点。压抑或孤独可有意留白，但须记录意图。
- 字、下划线和圈画作为一个整体计算边界；不得压住脸、手、关键道具或高密度门框。圈画完成后仍需检查。
- 人物缩小导致图文间无意义的大洞时，先调整人物尺度和文字锚点，不能默认把字塞到底部。留白是否合理以叙事判断，不以填满画面为目标。

## 2. 一次完成一个语义绘制单元
- 同一只笔同一时刻只服务一个绘制单元；人物绘制与手写文字原则上不重叠。自动字幕不属于手写事件。
- 写字必须完成一个完整意思再换对象；禁止写两个字便离开，回来续写半句。先写完整关键词，再完成它的下划线/圈画，再进入下一单元。
- 画图应完成一个可辨认的主体或叙事阶段再写字。允许“画妈妈→写妈妈的困境→画孩子→写孩子的状态”；禁止无意义地画几笔人物→写两字→再画几笔→补两字。
- 需要拆画时，分镜先声明阶段、可辨认的完成状态与拆分理由；不能以随机笔画比例切段。长复杂人物优先简化镜头或适当加快绘制，不通过反复跳笔填时长。
- 排程优先级：保留锁定声音和语义时点→完整语义单元→动作连续→静止上限。冲突时压缩非必要笔画/减少文字/重分画板；不得改音频或通过碎片交错凑事件数。
- 开头0.5秒人物起笔规则仍适用；需要先呈现钩子时用已经允许的非持笔文字呈现方式，并检查不造成第二支虚拟笔。

## 3. 区分重点文字与字幕
- 手写重点文字自由锚定到图像/语义，不固定上下两栏。
- 底部自动字幕用于连续阅读：同一画板位置固定，相邻画板尽量稳定；确有遮挡时可在换板点切换到另一个预先验收的安全位置，不逐句上下跳动。
- 先调整画面布局，再考虑字幕位置。字幕条与装饰分隔线作为同一组件移动，不留孤立横线。不擅自缩小字号或侵入平台遮挡区。
- 每板记录 text_anchor、layout_reason、subject_bounds、text_bounds_with_marks、caption_zone、intentional_whitespace、draw_units。正式渲染前由 check_composition.py 检查；语义与美感仍需过程目检。

## 4. 过程验收
- 每板检查起笔、各语义单元切换、文字完成、标记完成与最终状态；完成帧通过不能代替过程检查。
- 检查人物/文字事件重叠、半句中断、短时跨区域反复跳笔、图文关系、标题字幕遮挡。例外须写明语义依据并供独立审片复核。
- 每段检查均记录具体时间与证据；未看完整动画不得称完整审看。

## 5. 情绪与物件：用户已审核通过
- 批准的情绪：伤心（稀疏雨线）、焦虑（细乱线）、生气（短促向外锐线）、无力（下坠短线）、孤独（断续包围线与空白）、压力（上方压迫线）、释然（舒展弧线）、希望（少量橙色上扬光线）。
- 表情和动作是主信息，符号只是补充；同一板最多一种主情绪符号，强度分轻/中，禁止每逢伤心机械下雨。符号不遮脸、不暗示疾病诊断、不凭空增加剧情。
- 首批物件：手机、闹钟、日历、学校、书包、书、药板、体温计、房门、纸巾盒、对话框、台灯。药板/体温计仅表达原文已有情节，不暗示用药建议。
- 审核图仅用于确定造型。已按用户要求拆分为独立白底PNG及逐笔路径，登记id、含义、禁用语境、锚点、线宽、尺寸、许可/来源、哈希、审核状态；验证实际动画后方可替换粗糙旧物件。拆图必须去掉标签和邻图、逐张检查裁切边界并登记来源；本批为白底专用素材，不得冒称透明PNG。
- 源图已有物件不得再叠加同义小图；没有批准素材时报告缺口，不临时用粗略几何图替代。

## 6. 取消常驻标题
- 所有画幅、首板与后续板均不显示固定标题、歌名或角标标题。header_first 为两个空字符串，header_other 为空；渲染器不绘制该组件。
- 独立封面文案、随叙事出现的手写关键词、自动字幕不属于常驻标题，不因此删除。旧成片不自动改动。

## 7. 自动检测契约
- 正式渲染自动调用 scripts/check_composition.py；缺少 design/composition.json 或检测失败即停止。草稿允许跳过但不得称正式交付。
- composition.json: version=1；panels 每项包含 index、layout_reason、text_anchor、alternatives（至少两项）、caption_zone（x0,y0,x1,y1）、protected_bounds（脸/手/关键结构框列表）、text_bounds_with_marks（含圈线整体框）、intentional_whitespace（可为空）、draw_units。
- draw_units 每项包含 id、meaning、completion、events（spec.data.events 的全局下标）；每个事件必须且只能归属一个单元，同一单元不可被其他单元插断。可辨认的分阶段绘制应分别建单元，completion 描述阶段完成状态。
- 检查非空常驻标题、事件重叠、跨板、越界、遗漏/重复事件、单元交错、文字遮挡和字幕区冲突。大段纵向空白给警告；实际字形、漏标关键结构与语义质量不能由自动检测保证。
- 检查报告 qc/composition-check.json 必须与过程抽帧一起交独立审片，不得只凭 pass 宣称美感通过。

## 8. 已批准素材调用
- `assets/narrative-props-v01/manifest.json` 索引12件单图，`strokes.json` 是包内骨架路径；新项目自动复制到 assets/images。原审核图保留追溯，图上旧“待审核”字样不改变2026-10-28用户批准事实。
- 使用 `from hdv.props import draw`，`draw(F, panel, 'phone', cx, top, height, at, dur)`；按索引id调用，真实图片哈希不符即报错。借用既有hero描摹机制，禁止重新临时画粗陋几何替代物。
- 当前单图为原批准图裁切的白底版本，适用于白纸空白区，不覆盖人物，不用于彩底。透明提取两次产生灰雾，未采用；不静默把重新生成的版本替换批准图。
- 图中日历/时钟/体温计数字仅为示意，不能充当实际数据。学校等复杂图应留足绘制时间；小物件不得放大成主画面。
- 情绪使用 `from hdv.emotion_styles import draw`，`draw(F,panel,'sadness',x,y,width,height,at,dur,intensity='light')`；支持8类，参数以参考图的线条语法为依据，位置与强度按脸部避让。
- 情绪连续逐笔输出，不使用旧emo函数里互相重叠的时序。情绪参考图中的人物仅用于示意，不复制进视频。

- [ ] 试听消息列出 `voice-check.md` 每项红/黄提示的秒数、原句和问题；ASR 可疑字词带时间段并说明待人耳核实，不以时间戳对齐替代实际读音核对

## 人物（每张图）
- [ ] 实际生图工具（Claude/WorkBuddy 用 Codex CLI；Codex 用内置生图工具；Antigravity 用内置 image-generator 子代理）、工具/模型版本（可获得时）、提示词、调用方式、参考图、输出 SHA-256、对应原文已记录（qc/IMAGEGEN_LOG.md）
- [ ] 同一人（脸/发型/衣服）、年龄体态对、五官正常；**手逐只数：每人两只手、一左一右、各五指、无多出的手或手臂，放大看过并写进 shots.json 的 hands_check**；脚正常；母亲为漂亮、成熟有气质、修长匀称且打理得体的中年女性
- [ ] 学生第一人称稿：图里主角性别与配音一致（男声=男学生，女声=女学生）
- [ ] 表情和动作读得出该句口播情绪；纯白底、无文字
- [ ] 每个出镜妈妈/班主任镜头在 `wardrobe_references` 中选了正确参考图；CLI/内置生图调用均实际附加图像文件，`imagegen-run.json` 的 ref 与附件一致。妈妈逐镜选择衣服；老师服饰图与性别匹配。参考图只供衣服剪裁与廓形，脸、发型、表情、鞋子、眼镜、姿势、道具按本镜头重设
- [ ] 人物用色符合 STYLE_SPEC：白衣墨线、黑发、微橙；普通角色可用既有极淡肤色，陪伴师面部/皮肤/衣服白填；家具道具无上色
- [ ] 每图 ≤2 次；陪伴师场景图参考五张审核图且线上交流优先，参考图不直接入镜；`qc/asset-usage.json` pass

## 画面
- [ ] 版式不裁切；不压字幕带（y≥1438）和标题区（y≤285）
- [ ] 每块画板事件在窗口内结束，且最后一笔最晚在镜头开始离开（下一块起点前 0.5 s）后 0.2 s 内画完（事件表自检会拦截）
- [ ] `shots.json` 每张图记录 `source_objects`（图内已有物件及位置）和 `overlay_objects`（代码新增物件及原文依据）；逐板完成帧检查未重复重画源图对象，新增笔画未遮挡源图物件、人物表情或动作；确有强调性重画时记录必要性与不重叠位置
- [ ] 每个圈/叉/勾/箭头等符号在分镜或事件表中对应具体口播短语与含义；不能只以“指向明确”判通过，无明确语义锚点的符号删除
- [ ] 每块画板 2.5–8.0 s（短于 2.5 s 的并入相邻画板）；板内有效新笔画的最大空档 ≤4 s（字幕、镜头平移、静置的已画完元素不算新笔画）；自动检查无超限，渲染后逐板抽查运动过程，不能只看完成帧
- [ ] 橙色只有一种；字体为 LXGWWenKai / NotoSansSC-500
- [ ] 联系表目检（每块画板至少 1 帧，含转场帧）
- [ ] **画人物过程抽帧（2026-10-16 新增）**：抽人物刚画出 1/3、2/3 的帧，脸、身体上不得有没填上的白斑（皮肤、阴影、粗黑头发应随笔画先显出）；有白斑先查引擎是否为最新（hand_drawn_marker.js 含填色层，meta.split 分区补行），不要靠改图糊弄

## 音画
- [ ] sync-report "需检查"项已逐条看过；字幕与口播一致
- [ ] 结尾：口播后 1.5 s + 0.6 s 渐隐
- [ ] 混音：-16 LUFS、峰值 ≤ -1.5 dBTP；当前执行本工作流的 AI 工具已依据脚本自动选曲；配乐在 LICENSES.md 登记且可商用
- [ ] 没有任何音效（规范：本 Skill 不用音效）；配乐响度来自 bgm-levels.json 或自动默认 -28 LUFS，且已记录在混音报告
- [ ] 成片开头是已通过的封面（6 帧 ≈ 0.2 s），总帧数 = 正片帧数 + 6
- [ ] 最终 MP4 第 0 帧与已通过封面核对一致；第 6 帧开始混音正片；片头 6 帧静音，时长比混音正片多 0.2 s
- [ ] 已运行 `add_cover_intro.py`；未以单独 PNG、试听版或平台上传设置替代成片内的封面帧
- [ ] 交付回复给出完整成片路径，并明确说明是否为已定稿正式版
